# 📊 Sales Performance Dashboard | Power BI

## 📌 Project Overview

This project is an interactive **Sales Performance Dashboard** developed using **Microsoft Power BI**. The dashboard provides a clear and visual representation of sales performance, helping users understand important business metrics, identify trends, and analyze sales data effectively.

The project demonstrates the use of **data visualization, data analysis, KPIs, charts, filters, and interactive dashboard design** in Power BI.



## 🎯 Project Objectives

The main objectives of this project are:

* Analyze overall sales performance.
* Track important sales KPIs.
* Identify sales trends and patterns.
* Compare sales performance across different categories.
* Present complex sales data in an easy-to-understand visual format.
* Create an interactive dashboard for business decision-making.



## 🛠️ Tools & Technologies

* **Microsoft Power BI**
* **Power Query**
* **DAX (Data Analysis Expressions)**
* Data Visualization
* Data Cleaning & Transformation
* Interactive Dashboard Design



## 📊 Dashboard Features

The dashboard includes various interactive visualizations and performance indicators such as:

* 📈 Sales performance analysis
* 💰 Revenue/Sales KPIs
* 📊 Interactive charts and graphs
* 🔎 Filters and slicers
* 📋 Data-based performance analysis
* 📅 Trend analysis
* 📌 Category-wise analysis
* 📍 Interactive visual exploration

Users can interact with the dashboard using filters and slicers to explore different aspects of the sales data.
